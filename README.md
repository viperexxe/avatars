# LeMage Avatars - Premium phpBB Extension

Enhance your phpBB forum with modern circular avatars and last-post avatars on forum index and topic lists.

## Features
- **Circular Avatars**: Automatically styles all avatars to be perfectly circular with high-quality CSS.
- **Last Post Avatars**: Displays the avatar of the last poster on the Forum Index (index.php) and Topic List (viewforum.php).
- **Responsive Aesthetics**: Perfectly integrated with prosilver and modern child themes.
- **Gravatar Support**: Fully compatible with Gravatar for users without uploaded avatars.
- **Performance Optimized**: Uses efficient SQL queries and internal caching to reduce database load.

## Installation
1. Download the repository.
2. Copy the `lemage` folder into your phpBB `ext/` directory.
3. The resulting path should be `ext/lemage/avatars/`.
4. Navigate to the **ACP -> Customise -> Manage extensions**.
5. Find **LeMage Avatars** and click **Enable**.
